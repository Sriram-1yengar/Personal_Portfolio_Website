## Visual Direction — sriramiyengar.me

Improve the visual energy of the portfolio without turning it into a generic "AI developer" website.

### Overall aesthetic

Target:

> Premium technical portfolio / AI engineering lab / modern editorial website

Avoid:

* Generic purple/blue AI gradients
* Cyberpunk aesthetics
* Neon colors
* Matrix/code-rain effects
* Excessive glassmorphism
* Excessive particles
* Large decorative blobs
* Excessive animation

### Background

Replace an overly flat background with subtle visual depth.

Use:

* A warm or neutral base background
* Very subtle technical/data grid
* Extremely low-opacity geometric or network elements
* A soft radial accent glow behind the hero
* Slight background variation between major sections

The background should remain subordinate to the content.

### Hero

Add a very subtle radial accent glow behind the hero.

Optionally add a low-opacity technical/data visualization or node network behind the hero.

Keep all decorative elements below approximately 5–10% visual prominence.

### Project section

Make project cards more visually dynamic.

Cards should include:

* Project number
* Project title
* One-line problem statement
* Technical tags
* Small visual/architecture preview
* Explore CTA

On hover:

* Slight elevation
* Subtle accent border/glow
* Small image/diagram movement
* Arrow/CTA movement

Keep transitions fast and subtle.

### Visual language

Introduce a consistent technical motif:

* Thin lines
* Small labels
* Project numbering
* Architecture diagrams
* Data visualizations
* Subtle grids
* Technical annotations

Use this motif consistently rather than adding unrelated decorative graphics.

### Color

Use a restrained palette.

Approximately:

* 80–90% neutral tones
* 10–20% accent color

Use the accent primarily for:

* Links
* Metrics
* Project numbers
* Hover states
* Diagram highlights
* Important UI elements

### Animation

Use subtle animation only.

Prefer 10–30 second ambient animations over fast looping effects.

Respect `prefers-reduced-motion`.

Do not introduce animation that negatively affects performance or readability.

### Important

The site should feel more lively and distinctive while remaining credible for Data Scientist / Machine Learning Engineer recruiting.

The visual design should communicate:

> technical depth + engineering ability + personality

rather than:

> generic AI portfolio + visual effects.
